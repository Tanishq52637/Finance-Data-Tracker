# Personal Finance Tracker

Personal Finance Tracker is a responsive web application that helps users manage their finances by tracking income and expenses, monitoring monthly balances, and analyzing spending patterns through interactive dashboards and visual reports.

## 🚀 Features

### Financial Management

* Monthly Income Tracking
* Expense Recording
* Category-Based Expense Management
* Transaction Notes and Date Tracking

### Analytics & Insights

* Income, Expense & Balance Overview
* Category-Wise Spending Analysis
* Monthly Spending Visualization
* Interactive Financial Dashboard

### User Experience

* Responsive Interface
* Simple Transaction Entry
* Real-Time Dashboard Updates
* Browser-Based Data Persistence
